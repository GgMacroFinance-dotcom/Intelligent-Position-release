# 美国通胀、利率与美元资金面｜投资例会一页材料

**数据截止：2026-11-14（周六，执行时系统日期）；观察区间：2026-10-14—2026-11-14，按各序列最近可得观测；会议：2026-11-16（下周一）。**

## 结论
通胀同比在最新可得的9月数据中普遍回升：CPI、核心CPI、PCE及核心PCE均高于8月；10月CPI尚无数值，不能判断10月通胀变化。近月政策区间维持3.75%–4.00%，2年、10年美债收益率较10月14日分别升4bp、降9bp；短端回购利率与IORB大致贴近、准备金仍近3万亿美元，暂无明显美元融资挤压信号，但准备金近月下行、TGA回升，宜继续观察。**研究判断：通胀黏性限制宽松预期，长端利率回落与短端上行并存；资金面暂不显著紧张，不能据单一指标确认宽松。**

## 解读｜事实、预期与判断
- **已发生事实：** 最新CPI与PCE统计期均为9月，四项同比指标较8月走高；10月CPI在所取FRED序列中为缺值。政策区间稳定；近月10年收益率回落而2年收益率上升。SOFR相对IORB接近零利差，EFFR亦稳定；准备金下降、TGA上升，ON RRP余额很低。
- **市场预期：** 本次取数未包含利率期货/调查预期，**未取得**，不据此推断市场对下次FOMC的定价。
- **研究判断/投资含义：** 通胀同比回升不利于过早押注政策转松；长短端利率分化，利率风险仍需区分期限。短端融资指标未显示明显压力，但准备金回落与财政账户抽水方向值得监测，单看低ON RRP不足以认定资金宽松。
- **未来一周风险/节点：** 需关注是否发布10月CPI及相关通胀数据、联储官员表态、国债供给/结算对准备金的影响；本次数据工具未提供下周官方发布日程，具体日期**未取得**。上述均为待观察事项，不是已确认事件。
