## 怎么用

- 有 backlog 编号的条目，状态以 backlog 为准，这里记的是核对当天的状态。没有 backlog 编号的只记在这里。
- 做完一条，在同一个 PR 里改这里的状态。
- 状态用词和 backlog 一样：**完成**；**待做** 可以直接接；**等人** 要维护者或工程师本人动手；**待定** 要先有人拿主意。
- 第一、二组是公开的硬条件。第三组是打包前要先定的事。第四组不做也能发，但发布说明里要照实写“只用假服务测过”。
