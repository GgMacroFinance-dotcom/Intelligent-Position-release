# 官方通胀数据访问与发布时点核验

## 结论
截至 2026-11-11（UTC；本次复核抓取时间 16:10:46Z），可从 BEA 官方来源确认 2026 年 9 月 Personal Income and Outlays 新闻稿于 **2026-10-29 8:30 a.m. EDT** 发布；其 PCE 价格指数整体环比 **0.5%**、核心环比 **0.3%**、整体同比 **3.6%**、核心同比 **3.1%**。对应前期 2026 年 8 月：整体环比 0.3%、核心环比 0.3%、整体同比 3.4%、核心同比 3.0%。BEA 官方发布日历当前列示“Personal Income and Outlays, October 2026”于 **2026-12-02 8:30 AM** 发布，所以 10 月 PCE 截至 11 月 11 日尚未按该日历发布。

BLS 官方新闻稿、日历与档案页面在本环境均返回 HTTP 403；BLS API 可访问且把 2026 年 10 月 CPI 指数标记 `latest=true`，但这不是官方发布日期证明，故不能据此认定 10 月 CPI 已发布。本次仍未取得可复核的 CPI 新闻稿/日历或整体、核心 CPI 同比环比，不能补填该部分。原宏观简报文件在同事工作目录 `macro-1/reports/2026-11-11-美国通胀利率资金面一页简报.md`，不属于 ops-1 当前工作目录；本任务报告存放在本目录。

## 复现
1. `curl -L -sS --max-time 12 -o /tmp/b.$$ -w '%{http_code} %{size_download} %{url_effective}\\n' 'https://www.bls.gov/news.release/cpi.htm?x=1'`；输出 `403 1325 https://www.bls.gov/news.release/cpi.htm?x=1`，响应为 Access Denied HTML。
2. 对 `https://www.bls.gov/schedule/2026/2026_sched.htm`、`https://www.bls.gov/schedule/2026/11_sched.htm?x=1`、`https://www.bls.gov/news.release/archives/cpi_11122026.htm`、BLS 两个 RSS URL 同样执行 curl，全部 HTTP 403、1325 bytes。
3. `curl -sS --max-time 15 'https://api.bls.gov/publicAPI/v1/timeseries/data/CUUR0000SA0'` 成功；返回 `2026 October 337.511 latest=true`、`2026 September 336.940`。这只记录 API 响应，不作为发布证明。另一次临时请求脚本因超时返回非 series 响应，随后重试 API 成功，仍未据该 API 推断发布时间。
4. BEA 可访问性：`curl -L -sS --max-time 20 'https://www.bea.gov/news/2026/personal-income-and-outlays-september-2026'`，页面页眉/正文确认 `EMBARGOED UNTIL RELEASE AT 8:30 a.m. EDT, Thursday, October 29, 2026`，网页显示 last modified 10/29/26。`curl` 获取 `https://www.bea.gov/sites/default/files/2026-10/pi0926.pdf` 返回 HTTP 200、404608 bytes；历史比较表 `https://www.bea.gov/sites/default/files/2026-10/pi0926-hist.xlsx` 返回 HTTP 200、14018 bytes。
5. `pdftotext -layout /tmp/pi0926.pdf /tmp/pi0926.txt` 可提取新闻稿；`python3` 使用 openpyxl 读取 `/tmp/pi0926-hist.xlsx` 的 `PIOhist_M` sheet 可读出完整比较表。
6. BEA 发布日历：`curl -L -sS --max-time 20 'https://www.bea.gov/news/schedule'` 后解析页面，结果明确列出 `November 25 8:30 AM ... GDP ...`，及 `December 2 8:30 AM ... Personal Income and Outlays, October 2026`。PDF 内早期稿件写“Next release: November 25”，而截至本次复核的当前在线日历已把 10 月 PIO 列于 12 月 2 日；报告采用当前官方日历，并指出网页为后续日程版本。

## 原因
BLS 站点请求受到 Akamai/边缘访问控制，所有尝试的官方 CPI 新闻稿、发布日历、档案和 RSS 均被 403 拒绝；因此不是已有材料里的 CPI 数据本身缺失，而是当前网络访问路径拿不到官方页面内容。API 只提供序列观测值及 `latest` 标记，不含官方新闻稿发布日期证据，且返回未来月份时尤其不能替代发布日历。BEA 新闻稿与文件端点则可访问，因此可用官方稿件和其历史比较工作簿核验。

## 修改
本次只新增本运维工作目录报告，没有更改原简报或生产数据。记录已核实的 BEA 官方数值，并将 BLS 的 403 和 API 的证据局限明确分开；未绕过访问控制、未把 API 的未来观测期当作已发布月份、未推断 CPI 数值。

## 遗留风险
1. 必须取得 BLS 官方新闻稿和官方日历可读副本（或由用户提供官方发布文件/页面内容），方可核实 CPI 截至该时点的最后发布月份、发布日期和整体/核心同比环比及前期值。在这之前原简报 CPI 一栏应维持未核实。
2. BEA PDF 的“Next release November 25”与当前官方日历的 12 月 2 日不一致，推测日历有修订，但本报告不臆断修订原因；如需准确解释发布时间变更，需查官方变更记录/公告。截止状态按本次抓取的官方日历记录。
3. BEA 新闻稿和日历均是截至本次抓取的当前在线页面，报告保留本次核验时间；在线内容之后可能更新。
