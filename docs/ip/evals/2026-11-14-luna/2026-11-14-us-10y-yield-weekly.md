# 美国10年期国债收益率最近一周数据点评

## 结论
截至 FRED 最近可用观测日 2026-11-12，美国10年期国债收益率在本周（以 2026-11-06 为起点）总体上行：从 4.86% 升至 5.10%，累计上行 0.24 个百分点（24 个基点）。走势表现为连续观测日逐步走高；2026-11-11 数据缺失，因此不对该日走势作判断。另据美国财政部收益率曲线，2026-11-13 的10年期国债平价收益率为 5.15%。

## 关键数据表

| 日期 | 10年期收益率 | 说明 |
|---|---:|---|
| 2026-11-06 | 4.86% | FRED DGS10 |
| 2026-11-09 | 4.88% | FRED DGS10 |
| 2026-11-10 | 4.98% | FRED DGS10 |
| 2026-11-11 | 未取得 | FRED 返回缺失值 |
| 2026-11-12 | 5.10% | FRED DGS10；最近可用观测 |
| 2026-11-13 | 5.15% | 美国财政部每日平价收益率曲线；补充最新观测，口径与 FRED 序列不同 |

## 解读
- 以 FRED DGS10 的周初和最近可用观测比较，收益率抬升 24 个基点；已取得的日度观测从 2026-11-06 的 4.86% 经 2026-11-09 的 4.88% 和 2026-11-10 的 4.98%，升至 2026-11-12 的 5.10%。
- 2026-11-11 的观测缺失，故无法确认当日是否延续或逆转前一日变化。2026-11-13 财政部曲线提供的 5.15% 是另一来源、另一观测日的平价收益率，不与 FRED 的 2026-11-12 数值混作同一观测。
- 本次数据只说明收益率方向和幅度；仅凭这组收益率序列无法识别上行的具体驱动因素，故不作归因。

## 风险与待观察
- 后续关注收益率上行是否延续，以及缺失日之后的日度变化；当前已取得的 FRED 观测截至 2026-11-12。
- 不同来源的指标口径及观测日期不完全相同，比较时应优先保持同一序列、同一口径。

## 数据来源
- FRED，DGS10（美国10年期国债收益率；单位：%），Finance Macro Data API 返回的日度观测：2026-11-06 至 2026-11-12；其中 2026-11-11 为缺失值。数据截至 2026-11-12。
- 美国财政部每日平价收益率曲线（Treasury par curve）：10年期 5.15%，观测日期 2026-11-13。
