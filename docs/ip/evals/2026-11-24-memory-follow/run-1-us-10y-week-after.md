# 美国10年期国债收益率周度点评

## 结论
最近一周按最近5个交易日口径（2026-11-16至2026-11-20），美国10年期国债收益率从5.12%降至4.92%，累计下行0.20个百分点。查询结果最新观测日期为2026-11-20，因此本点评不覆盖2026-11-23和2026-11-24。

## 关键数据表

| 观测日期 | 美国10年期国债收益率（%） |
|---|---:|
| 2026-11-16 | 5.12 |
| 2026-11-17 | 5.10 |
| 2026-11-18 | 5.07 |
| 2026-11-19 | 5.04 |
| 2026-11-20 | 4.92 |

## 解读
在可得的5个交易日观测中，收益率逐日回落，区间累计下降0.20个百分点（20个基点），从2026-11-16的5.12%降至2026-11-20的4.92%。2026-11-20是本次查询中最新可得观测日；FRED序列在2026-11-23和2026-11-24没有返回观测，因此本点评不覆盖这两个日期，不能视为截至报告日的完整最近一周。

## 风险与待观察
收益率变化本身不能识别驱动因素；本次仅查询10年期收益率，未结合通胀、就业、政策预期或期限溢价等数据，因而不对下行原因作归因。后续走势可能变化，需关注后续可得收益率数据及相关宏观信息。
